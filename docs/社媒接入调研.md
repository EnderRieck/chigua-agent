# 社交媒体接入调研（2026-10-27）

目标：为吃瓜智能体找现成的、可被 LLM 调用的小红书 / 微博 / 知乎 / X 访问能力（Claude Skills 或 MCP Server）。

结论：四个平台都没有面向个人开发者的官方开放搜索 API，社区方案基本都是 **MCP Server**（以非公开接口或浏览器自动化实现）；
"Skill" 形态的只有小红书有一两个，而且都是套在 MCP 之上的使用说明。本项目因此采用 **自研轻量适配器 + 可选挂接 MCP** 的方式。

## 二、本项目的取舍

| 平台 | 实现 | 降级链 |
|---|---|---|
| 微博热搜 | 用户自己的 `WEIBO_COOKIE` 直连 `weibo.com/ajax/side/hotSearch` | → 60s 公开镜像 |
| 微博搜索 | `WEIBO_COOKIE`（桌面端）直连 `s.weibo.com` 搜索页并解析 HTML，支持 综合/热门/实时；m.weibo.cn 接口要求手机端登录态，桌面 Cookie 会被跳转 | → DeepSeek `site:weibo.com` |
| 知乎热榜 | 公开接口直连 | — |
| 知乎搜索 / 问题回答 | 用户本人 `ZHIHU_COOKIE` + 本地计算 x-zse-96 签名直连 `api/v4/search_v3`、`questions/{id}/answers` | → DeepSeek `site:zhihu.com` |
| 小红书 | 本地 xiaohongshu-mcp（MCP 客户端调用 `search_feeds` / `get_feed_detail`） | → DeepSeek `site:xiaohongshu.com` |
| X | xAI `x_search`（Responses API） | → Grok Live Search（chat.completions `search_parameters`）→ DeepSeek `site:x.com` |

设计原则：
1. **不绕过平台风控**：微博对匿名访问返回 432 / 跳转 passport，本项目不伪造访客身份，只用用户本人 Cookie 或公开镜像。
2. **拒绝幻觉帖子**：X 的两条模型侧链路都要求接口返回引用（citations / 工具调用痕迹），否则判定为中转站未真正联网并降级。
3. **所有来源统一进证据库并编号**，分析员必须用 `[E#]` 引用，报告自动附来源列表。

## 三、DeepSeek / xAI 接口要点（来自官方文档）

- DeepSeek Search：`POST https://api.deepseek.com/v1/tools/search`，body `{query(≤128字), count(1-50), need_content}`，
  返回 `results[]`（title/url/snippet/summary/content/date/site_name/rerank_score/authority）。支持 `site:` `after:` `before:` 操作符。
- DeepSeek Fetch：`POST /v1/tools/fetch`，body `{url}`，返回 `{title, content(Markdown)}`。
- 价格：各 $0.75 / 千次成功请求，2026-11-01 00:00（北京时间）起计费；限速 Search 100 QPS、Fetch 25 QPS。
- xAI：Responses API `client.responses.create(model, input, tools=[{"type":"x_search"}, {"type":"web_search"}])`，
  OpenAI SDK 指向 `https://api.x.ai/v1`。文本模型当前有 grok-4.7 / 4.6 / 4.5（$2/$6 每百万 token）、grok-4.3（$1.25/$2.5，1M 上下文）。

来源：[DeepSeek Search 指南](https://api-docs.deepseek.com/guides/search)、[xAI 工具总览](https://docs.x.ai/docs/guides/tools/overview)、[xAI 模型与定价](https://docs.x.ai/docs/models)。
